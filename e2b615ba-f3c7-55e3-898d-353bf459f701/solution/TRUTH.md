# Golden trajectory

## Ordered path

1. Reproduce each report with the minifier's fixture runner (compress defaults, the named options) and node; read the emitted code to find the transform that changes behaviour.
2. Live imports: imported named and default bindings can change outside the module; treat them as possibly changing wherever the optimizer checks for reassignment (inlining, sequence merging, side-effect ordering), but keep namespace objects stable.
3. Default parameters: the usage analyzer must not count references inside function parameters, method/constructor/accessor bodies as references of the enclosing value, so a function or object named by a default is not inlined into it.
4. super calls: (0, super.method) is a callee whose this-binding matters exactly like a member expression; keep the sequence wrapper.
5. Inferred names: when keep_fnames/keep_classnames is set, keep the (0, ...) in front of an anonymous function, arrow or class that would otherwise get an inferred name.
6. Class self-references under keep_classnames: when the renamer rebinds a class's internal references to the class expression's own name, update their syntax context even if the spelling does not change, including shorthand properties and destructuring shorthands, so the outer rename does not capture them.
7. Constant factors: reassociate * only when exact (a factor of +-1, or two finite powers of two of magnitude at least 1).
8. Run the minifier's exec suites and the other packages' tests to confirm nothing that worked regressed.
