# Golden trajectory

## Ordered path

1. Reproduce the issue: compress `function a() {} function b() { b() } function c() { d() } function d() { c() }` as an ES module with unused-code removal; `a` goes, `b`, `c` and `d` stay because their own references keep the reference counts above zero.
2. Decide removal by reachability: a function declaration is dead when every reference to it lies inside the scope of some dead function (the greatest fixed point over all function declarations, at every depth), recomputed from the current semantic references after every pass so cycles exposed by other removals (dead branches, a dropped direct eval) are found.
3. Apply the same reachability in dead-code-elimination-only compression and for CommonJS and scripts, and remove var/let/const bindings (for initializers included) initialized directly with a function or arrow function whose every reference lies inside it.
4. Protect what is observable without a recorded reference: exports (named, default, specifiers, not type-only), a script's root bindings, unhoisted sloppy-mode block functions whose evaluation writes an outer binding, using declarations, and scopes with direct eval.
5. Make every count-based consumer honour the same observability: once a dead cycle that held the last read of an exported binding is removed, its initializer, assignments, member writes and async/generator IIFE value must stay.
6. Rebuild offline and rerun `cargo test -p oxc_minifier`, so every test that passed before still passes.

## Deliverables and red lines

- `D1` at `Rust sources under /app/crates/oxc_minifier/src`: With unused-code removal on, the minifier removes every function declaration whose every reference lies inside functions removed under the same rule or in code that can never run, and every var/let/const binding (for initializers included) initialized directly with a function or arrow function expression whose every reference lies inside that function, at every nesting level, for ES modules, CommonJS and scripts, in full and dead-code-elimination-only compression.
- `D2` at `Rust sources under /app/crates/oxc_minifier/src`: Everything observable keeps behaving as before: exported bindings and what they observe, a script's global bindings, sloppy-mode block-function aliases, using-declaration disposal, direct eval, and every function a reachable reference reaches.
- `RL1`: The graded result is computed from Rust sources under crates/oxc_minifier/src alone; crates/oxc_minifier/tests, the other crates, every Cargo.toml, Cargo.lock, build scripts, .cargo/ and every other build file are taken from the pristine base before grading. Enforced by tests/grading/grade.sh, which copies the agent's crates/oxc_minifier/src onto /opt/base-src, the base with the hidden test patch, and drops symlinks.
- `RL2`: No network is reachable from the agent environment, so the merged fix and crates.io cannot be fetched. Enforced by environment and agent network_mode no-network.
- `RL3`: Every test that passed at the base commit with the hidden tests applied must run and pass afterwards, counted per test target by name and count, including the upstream change's own pass-to-pass keep-guards; a target that runs fewer tests than at base counts as failed. Enforced by the frame in tests/grading/summarize.py against tests/grading/private/base-frame.json, and the reward gate in tests/test.sh.
- `RL4`: Class declarations and variables the stated rule does not reach (mutual arrow-function cycles, wrapped initializers, for-in/of heads) are outside the requirement: the grader neither requires nor forbids removing them where the removal is unobservable. Enforced by the hidden test patch, which drops every upstream assertion that pins either choice.

## Rejected routes

- `headline`: Stop at the reproducer: in each statement list, remove function declarations whose references all sit inside the bodies of such declarations of the same list (a fixed point over siblings), in the full-compression statement pass. Earns R1, R2, R4 and R9 (0.5946 with the judge); misses function-valued bindings (R3), DCE-only mode (R6, which visits statements without that pass), and every observer a removed cycle held a read for (R5, R7, R8).
- `headline_plus_one`: The headline fix plus self-referencing function-valued bindings, guarded against exports, script globals and redeclarations: adds R3 (0.6757); R5 to R8 still fail.
- `kw_export_blind`: The headline-plus-one binding rule without the export, script-global and redeclaration guards: it removes `export const f = () => f()` and the initializer an `export var f;` redeclaration exports, so the upstream keep-guards keep_reachable_self_recursive_function_valued_declarators and keep_recursive_cycle_with_exported_redeclaration fail, the frame fails and the reward is 0.
- `m_substitute`: The reference fix with its substitute_alternate_syntax change reverted: an empty async or generator IIFE initializing an `export var` redeclaration collapses to `void 0` once the dead cycle that read it is removed; R7 fails.
- `m_alt_no_annexb`: The alternate fix without the unhoisted sloppy block-function observer: duplicate block functions and the Annex B alias member write are removed; R5, R6 and R8 fail.
- `m_alt_no_dce`: The alternate fix with reachability disabled in dead-code-elimination-only mode: R6 and the DCE half of R8 fail.
